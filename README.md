# واصل — تواصل المنشأة على الشبكة المحلية

تطبيق سطح مكتب بواجهة عربية RTL، يعمل داخل الشبكة المحلية دون الاعتماد على خدمة سحابية أو اتصال بالإنترنت أثناء الاستخدام. يُغلف كتطبيق Windows عبر Electron.

## ما يتضمنه النموذج الأولي

- يعلن المضيف عن الغرفة على الشبكة بواسطة UDP، وتكتشفه النسخ الأخرى تلقائياً.
- ينشئ أي مستخدم غرفة مؤقتة؛ التطبيق نفسه يظل مفتوحاً على جهاز المضيف ما دامت الغرفة مستخدمة.
- دردشة فورية بين الأجهزة، وإظهار الأعضاء المتصلين.
- إرسال وتنزيل الملفات (حتى 10 ميغابايت في النموذج الأولي).
- واجهة بدء اتصال صوتي/مرئي تجريبي باستخدام WebRTC واتصالات LAN مباشرة.
- سجّل الرسائل النصية في ذاكرة المضيف فقط؛ لا يحتفظ بها التطبيق بعد إغلاقه.

## المتطلبات الشبكية

1. جميع الأجهزة على الشبكة المحلية نفسها، وبإمكانها الاتصال ببعضها (لا عزل بين عملاء Wi-Fi).
2. السماح للتطبيق على جهاز المضيف عبر جدار حماية Windows على **الشبكات الخاصة**. المنافذ الافتراضية: TCP `43821` لخدمة الغرفة، UDP `43820` للاكتشاف، بالإضافة إلى حركة UDP التي يحتاجها WebRTC للصوت/الفيديو.
3. لا يلزم إنترنت بعد تثبيت التطبيق. لا يستخدم التطبيق STUN/TURN أو CDN في النسخة الحالية.
4. إذا لم يظهر المضيف تلقائياً، فتح الجدار الناري أو عزل العملاء بالشبكة هو أول ما ينبغي فحصه.

## التطوير محلياً

يتطلب Node.js 20 أو أحدث.

```bash
npm install
npm start
```

على المضيف اضغط **إنشاء غرفة جديدة**. على بقية الأجهزة شغّل التطبيق نفسه؛ ستظهر الغرفة تلقائياً بعد استقبال إعلان الشبكة.

## بناء Windows

على Windows أو عبر GitHub Actions:

```bash
npm ci
npm run build:win
```

يخرج المثبت ونسخة portable في `release/`. وللبناء عبر GitHub: شغّل سير العمل **Build Windows installer** من تبويب Actions، ثم نزّل artifact المسمى `wasel-windows-installers`.

## قيود وملاحظات قبل الاستخدام المؤسسي

هذا **نموذج أولي قابل للبناء** وليس إصداراً إنتاجياً معتمداً: لا توجد حسابات/صلاحيات، أو تشفير طرفي، أو أرشفة دائمة، أو سجل تدقيق، أو استعادة للمضيف عند خروجه. المضيف يستطيع تمرير المحتوى، لذا استخدمه على شبكة داخلية موثوقة فقط إلى أن تضاف المصادقة والتشفير وسياسة الاحتفاظ.

تم إعداد أساس WebRTC للصوت والفيديو محلياً، لكن توافق الكاميرات والجدار الناري وحالات أكثر من مشاركين تحتاج اختباراً على أجهزة المنشأة الفعلية. قد يتطلب اتصال الصوت/الفيديو فتح منافذ UDP إضافية أو تعديلات في جدار الحماية. يختلف نجاح اكتشاف البث UDP وفق إعدادات الشبكة ونقاط الوصول.

الرسائل والملفات حاليّاً تمر عبر المضيف المركزي المؤقت؛ مشاركة الملفات ترسل نسخة مضمّنة وتقتصر على 10 ميغابايت لتفادي استهلاك الذاكرة. لا تشارك بيانات حساسة قبل استكمال ضوابط الأمن.

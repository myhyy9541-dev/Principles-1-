# واصل — تواصل المنشأة على الشبكة المحلية

تطبيق سطح مكتب Windows بواجهة عربية RTL، يعمل داخل شبكة المنشأة دون الاعتماد على خدمة سحابية أو اتصال بالإنترنت أثناء الاستخدام. الإصدار الحالي `0.2.0`.

## الوظائف

- اكتشاف الغرفة تلقائياً عبر بث UDP داخل الشبكة المحلية.
- إنشاء غرفة مؤقتة على جهاز أحد المستخدمين؛ الأجهزة الأخرى تتصل به تلقائياً عند العثور عليه.
- دردشة فورية مع حفظ آخر 1000 رسالة نصية على جهاز المضيف واستعادتها عند إعادة تشغيله.
- مشاركة الصور والملفات وتنزيلها، مع معاينة الصور الشائعة؛ 10 ميغابايت كحد أقصى للملف، و1 غيغابايت للمرفقات على جهاز المضيف.
- مكالمات صوتية ومرئية مباشرة عبر WebRTC محلياً، مع كتم الميكروفون وإيقاف الكاميرا وإنهاء المكالمة.
- واجهة وحالات اتصال ورسائل أخطاء باللغة العربية.

## التشغيل داخل المنشأة

1. ثبّت التطبيق على أجهزة Windows المتصلة بالشبكة المحلية نفسها.
2. شغّل التطبيق على جهاز المضيف، ثم اضغط **إنشاء غرفة جديدة** واترك التطبيق مفتوحاً.
3. شغّل التطبيق على أجهزة الفريق؛ سيبحث عن المضيف وينضم إلى الغرفة تلقائياً.
4. اسمح للتطبيق على جهاز المضيف عبر جدار حماية Windows ضمن **الشبكات الخاصة**. المنافذ الافتراضية: TCP `43821` لخدمة الغرفة، UDP `43820` للاكتشاف، وحركة UDP لاتصال WebRTC.

إذا لم يظهر المضيف تلقائياً، تحقق من عدم تفعيل عزل عملاء Wi-Fi، ومن السماح بالمرور بين الأجهزة. إذا تعذر إنشاء الغرفة، تحقق من أن منفذ TCP `43821` غير مشغول بنسخة أخرى.

## البيانات والخصوصية

- يحفظ المضيف سجل الرسائل والملفات في مجلد بيانات التطبيق الخاص بمستخدم Windows (Electron `userData`، ضمن مجلد `wasel-room`). لا تُرسل البيانات إلى الإنترنت.
- الرسائل النصية محدودة بـ5000 حرف، وتوجد حدود لمعدل الرسائل والملفات لتقليل الإغراق.
- الملفات المشتركة محفوظة على قرص المضيف، وتبقى متاحة ما دام المضيف يشغّل التطبيق وعلى الشبكة.

**تنبيه أمني:** نقل Socket.IO وHTTP داخل الشبكة غير مشفّر، ولا توجد حالياً حسابات مستخدمين أو كلمات مرور للغرفة أو صلاحيات أو سجل تدقيق. أي جهاز يستطيع الوصول إلى منفذ المضيف قد ينضم أو يقرأ المحتوى/الملفات المتاحة. لذلك اقتصر على شبكة داخلية موثوقة، ولا تستخدمه لتبادل معلومات حساسة أو سرية قبل إضافة المصادقة والتشفير. لا يحتوي التوزيع الحالي على توقيع رقمي من ناشر Windows، وقد يعرض SmartScreen تحذيراً.

## التطوير والاختبار

يتطلب Node.js 20 أو أحدث.

```bash
npm ci
npm start
npm test
```

تشمل اختبارات المشروع استعادة السجل، حفظ الملفات وتنزيلها، رفض البيانات غير الصالحة/الأكبر من الحد، ومنع تجاوز طول السجل.

## بناء Windows

```bash
npm ci
npm test
npm run build:win
```

ينشئ Electron Builder ملف تثبيت NSIS في مجلد `release/`. لإنشاء نسخة portable:

```bash
npm run build:portable
```

يمكن أيضاً تشغيل سير العمل **Build Windows installer** من تبويب GitHub Actions، ثم تنزيل artifact `wasel-windows-installers`. يعيد سير العمل تشغيل الاختبارات قبل البناء.

## ما يحتاج اختباراً عملياً قبل الاعتماد الرسمي

تم التحقق برمجياً من الاختبارات وبناء ملف التثبيت، لكن لم يُنفّذ اختبار متعدد الأجهزة على شبكة المنشأة نفسها. يلزم اختبار اكتشاف الشبكة وجدار الحماية وجودة الصوت/الفيديو مع الأجهزة والكاميرات الفعلية، ثم استكمال TLS ومصادقة الغرفة وتوقيع Windows قبل نشره على نطاق واسع.

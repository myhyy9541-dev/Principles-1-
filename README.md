# واصل — تواصل المنشأة على الشبكة المحلية

تطبيق سطح مكتب Windows بواجهة عربية RTL، يعمل داخل الشبكة المحلية دون الاعتماد على خدمة سحابية أو اتصال بالإنترنت أثناء الاستخدام. الإصدار الحالي `0.3.0`.

## الوظائف

- اكتشاف الغرفة تلقائياً عبر بث UDP داخل الشبكة المحلية.
- إنشاء غرفة مؤقتة على جهاز أحد المستخدمين؛ تبقى البيانات المؤقتة والرسائل في مخزن ذلك المضيف، لذلك يجب أن يبقى التطبيق مفتوحاً.
- محادثة عامة، ومحادثات فردية، ومجموعات خاصة بأعضائها، ورسائل بث لجميع الأجهزة التي سبق أن انضمت.
- حفظ سجل المحادثات على المضيف (حتى 5000 عنصر)، مع ترحيل الرسائل العامة من إصدار 0.2.0.
- رسائل مباشرة ومجموعات وبث محفوظة في طابور المضيف وتُسلّم عند عودة المستلم، مع إيصالات تسليم وقراءة.
- بحث في المحادثة الحالية وتصديرها إلى CSV.
- مشاركة ملفات متعددة أو اختيار مجلد كامل؛ تُنقل الملفات بشكل منفصل وتُحفظ مسارات المجلدات ضمن أسمائها النسبية. حد الملف 10 ميغابايت، والحصة الإجمالية للمرفقات 1 غيغابايت على جهاز المضيف.
- رفع مجزّأ يظهر تقدمه، مع إيقاف واستئناف وإلغاء. إذا انقطع الاتصال أثناء بقاء التطبيق والملف الأصلي مفتوحين، يمكن استئناف النقل من آخر مقطع مؤكد؛ يحتفظ المضيف بالأجزاء المؤقتة لاستكمال النقل.
- معاينة صور شائعة ومكالمات صوتية ومرئية مباشرة عبر WebRTC محلياً، مع كتم الميكروفون وإيقاف الكاميرا وإنهاء المكالمة.
- واجهة وحالات اتصال ورسائل أخطاء باللغة العربية.

## تشغيل المنشأة وتحديث الإصدار

1. ثبّت الإصدار نفسه على أجهزة Windows المتصلة بالشبكة المحلية نفسها. يتطلب هذا الإصدار تحديث تطبيق جميع الأجهزة كي تعمل الهوية والمجموعات الجديدة.
2. شغّل التطبيق على جهاز المضيف، ثم اضغط **إنشاء غرفة جديدة** واترك التطبيق مفتوحاً.
3. شغّل التطبيق على أجهزة الفريق؛ سيبحث عن المضيف وينضم إلى الغرفة تلقائياً.
4. اسمح للتطبيق على جهاز المضيف عبر جدار حماية Windows ضمن **الشبكات الخاصة**. المنافذ الافتراضية: TCP `43821` لخدمة الغرفة، UDP `43820` للاكتشاف، وحركة UDP لاتصال WebRTC.
5. تظهر جهات الاتصال المعروفة بعد اتصالها مرة واحدة. الرسائل الخاصة والمجموعات والبث غير المتصل لا تُرسل خارج المضيف؛ إذا أُطفئ المضيف فلن يستطيع حفظ الرسائل الجديدة أو تسليم الطابور حتى يعود.

إذا لم يظهر المضيف تلقائياً، تحقق من عدم تفعيل عزل عملاء Wi-Fi، ومن السماح بالمرور بين الأجهزة. إذا تعذر إنشاء الغرفة، تحقق من أن منفذ TCP `43821` غير مشغول بنسخة أخرى.

## البيانات والخصوصية

- يحفظ المضيف السجل والمجموعات وجهات الاتصال والملفات وأجزاء النقل في مجلد بيانات التطبيق الخاص بمستخدم Windows (Electron `userData`، ضمن مجلد `wasel-room`). لا تُرسل البيانات إلى الإنترنت.
- الرسائل النصية محدودة بـ5000 حرف، وتوجد حدود لمعدل الرسائل والملفات لتقليل الإغراق.
- الملفات محفوظة على قرص المضيف، وتبقى متاحة ما دام المضيف يشغّل التطبيق وعلى الشبكة.
- تُعرّف الأجهزة بمعرّف محلي محفوظ في إعدادات التطبيق؛ هذا **ليس بديلاً عن تسجيل دخول أو مصادقة تشفيرية**.

**تنبيه أمني مهم:** نقل Socket.IO وHTTP داخل الشبكة غير مشفّر، وسجل المضيف محفوظ محلياً دون تشفير. لا توجد حالياً حسابات مستخدمين أو كلمات مرور للغرفة أو صلاحيات إدارية أو سجل تدقيق. أي جهاز يستطيع الوصول إلى منفذ المضيف قد يحاول الانضمام أو الوصول إلى المحتوى والملفات. اقتصر على شبكة داخلية موثوقة، ولا تستخدمه لتبادل معلومات حساسة أو سرية قبل إضافة المصادقة والتشفير واختبارهما. لا يحتوي التوزيع على توقيع رقمي من ناشر Windows، وقد يعرض SmartScreen تحذيراً.

## التطوير والاختبار

يتطلب Node.js 20 أو أحدث.

```bash
npm ci
npm start
npm test
```

تشمل الاختبارات استعادة وترحيل السجل، وعزل المحادثات الخاصة، وطابور غير المتصلين، وعضوية المجموعات، واستئناف نقل مقطع ملف بعد إعادة فتح مخزن المضيف، وحفظ الملفات ورفض البيانات غير الصالحة، وضبط طول السجل.

## بناء Windows

```bash
npm ci
npm test
npm run build:win
```

ينشئ Electron Builder ملف تثبيت NSIS ونسخة portable في مجلد `release/`. يمكن أيضاً تشغيل سير العمل **Build Windows installer** من تبويب GitHub Actions، ثم تنزيل artifact `wasel-windows-installers`. يعيد سير العمل الاختبارات قبل البناء.

## ما يحتاج اختباراً عملياً قبل الاعتماد الرسمي

تم التحقق برمجياً من الوظائف والاختبارات. يلزم اختبار متعدد الأجهزة على شبكة المنشأة نفسها لجدار الحماية، والبث، وتسليم الرسائل والملفات بعد انقطاع فعلي، وجودة الصوت/الفيديو، ثم استكمال TLS ومصادقة الغرفة وتوقيع Windows قبل النشر واسع النطاق.

# واصل — مراسلة المنشأة عبر LAN

**واصل Java 0.8.1** تطبيق سطح مكتب عربي يعمل داخل شبكة المنشأة دون اعتماد تشغيلي على الإنترنت. خادم الغرفة، اكتشاف الشبكة، التخزين، الإعدادات، وإدارة الملفات مبنية بـJava 21؛ أما الواجهة فتعمل داخل Chromium مضمن عبر JCEF. حزمة Windows ترفق Java Runtime وملفات Chromium اللازمة، فلا يحتاج المستخدم تثبيت Java منفصلاً.

تحويل Java مستقل ولم ينسخ شيفرة LAN Messenger المرخصة بـGPL. مصدر Electron السابق محفوظ كسجل تطوير قديم؛ سير Windows الحالي يبني `java-app/` فقط.

## الميزات

- اكتشاف المضيف عبر UDP على الشبكة المحلية، مع غرفة مؤقتة تستمر ما دام المضيف فاتح التطبيق.
- اسم عرض لكل جهاز، اختيار بطاقة الشبكة وعرض IPv4 والقناع وعنوان MAC، وضبط فترة الاكتشاف.
- اتصال تلقائي أو يدوي، مظهر فاتح/داكن، وخيار تشغيل واصل عند تسجيل الدخول إلى Windows.
- دردشة عامة وخاصة ومجموعات وبث، مع حفظ الرسائل وإيصالات التسليم والقراءة وسجل لا يفرض سقفاً عددياً ثابتاً.
- مشاركة صور وملفات ومجلدات، نقل مجزّأ قابل للاستئناف ومؤشر تقدم، وسحب وإفلات إلى المحادثة.
- معاينة داخل التطبيق للصور والصوت والفيديو وPDF والملفات النصية، مع تنزيل الأنواع الأخرى.
- فتح معاينة الصورة بالنقر على المصغّر، تجهيز التنزيل خارج خيط واجهة المتصفح، وبث اكتشاف تلقائي على بطاقات الشبكة النشطة.
- مكالمات صوت وفيديو WebRTC في شبكة Mesh؛ الدعوات جماعية عبر المضيف المؤقت وفردية في P2P، مع رسائل صوتية بالضغط المطوّل.
- مجلد تنزيل افتراضي وتنبيهات صوتية قابلة للتعطيل، وواجهة عربية RTL تعمل دون CDN.

## تثبيت Windows

تنزيلات الإصدار 0.8.1 المباشرة:

- [مثبّت Windows EXE](https://github.com/myhyy9541-dev/Principles-1-/releases/download/v0.8.1/Wasel-LAN-0.8.1.exe)
- [نسخة محمولة ZIP](https://github.com/myhyy9541-dev/Principles-1-/releases/download/v0.8.1/Wasel-LAN-0.8.1-portable.zip)

ثبّت الإصدار نفسه على جميع أجهزة المنشأة؛ أجهزة Electron السابقة لا تستخدم بروتوكول الاكتشاف الجديد.

في أول تشغيل، اسمح لواصل في Windows Defender Firewall على شبكة **Private** فقط إذا ظهرت مطالبة. يجب أن تكون الأجهزة على الشبكة المحلية نفسها، وأن يسمح الراوتر بالبث المحلي وألا يمنع اتصال أجهزة Wi-Fi ببعضها. الاكتشاف لا يعبر غالباً الشبكات الفرعية؛ يمكن استخدام IP يدوي عند وجود توجيه ومنافذ مسموحة.

## بناء واختبار Java

المتطلبات: JDK 21 وMaven. من مجلد `java-app/`:

```bash
mvn clean test
mvn package
```

بناء Windows يتطلب Windows وWiX مع `jpackage`؛ يجهزها سير GitHub Actions تلقائياً، ويضم Java Runtime وJCEF في المثبت والنسخة المحمولة. بناء Windows لا ينتج من Linux وحده.

## البيانات والخصوصية والحدود

يحفظ Windows إعدادات التطبيق والسجل تحت `%APPDATA%\\wasel-lan`. الملفات والمرفقات موجودة على جهاز المضيف؛ لذلك يتوقف توفر الغرفة إذا أُغلق المضيف المؤقت. يدعم الملف الواحد حتى 1 GiB، وسعة تخزين المشاركة على المضيف حتى 10 GiB؛ سجل الرسائل لا يفرض حداً عددياً ثابتاً ويعتمد عملياً على مساحة القرص. يسعى التطبيق إلى نسخ بيانات غرفة Electron السابقة تلقائياً عند أول تشغيل Java إذا وُجدت.

**مهم:** الاتصال المحلي الحالي غير مشفر طرفاً إلى طرف، ولا يتضمن تسجيل حسابات أو أدواراً إدارية؛ أي جهاز مسموح له بالوصول لمنافذ LAN قد يحاول الانضمام. استخدم شبكة داخلية موثوقة فقط، ولا تتبادل بيانات سرية قبل إضافة المصادقة والتشفير واختبارهما. مكالمات الوسائط تعتمد على إعدادات خصوصية Windows والعتاد؛ يجب اختبار الكاميرا والميكروفون فعلياً على Windows قبل تعميم التطبيق. النسخة لا تحمل توقيعاً رقمياً من ناشر Windows، وقد يعرض SmartScreen تحذيراً.
